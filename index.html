Quick Start

Up & Running
in Minutes

No accounts, no cloud, no drivers to hunt down. Install Node 20.11+, start the bridge and pair once.

STEP 01

Start the bridge

Run node server/src/index.js serve or launch the installed app, then open http://127.0.0.1:8787/. No phone? The bundled demo snapshot still opens every screen.

STEP 02

Pair your phone

Enable Wireless debugging (or connect USB) and press Pair. Scan the QR code or type the six-digit code — the fingerprint is pinned for every reconnect.

STEP 03

Make it yours

Press Ctrl+K for universal search, enable clipboard sync, mount the drive, then tune snap layouts and shortcuts. Stuck? The troubleshooting matrix is one click away.
